# RealWaste 資料集來源與授權

本專案使用的 RealWaste 影像來源於 Whyte's Gully Waste and Resource Recovery facility（澳洲 Wollongong, NSW）。

- 原始資料集專案：RealWaste
- 原始論文：[RealWaste: A Novel Real-Life Data Set for Landfill Waste Classification Using Deep Learning](https://www.mdpi.com/2078-2489/14/12/633)
- 授權：CC BY-NC-SA 4.0
- 授權頁面：<https://creativecommons.org/licenses/by-nc-sa/4.0/>

資料只能依照授權條款使用。若發表報告、論文或展示成果，應引用原始論文並保留資料來源及授權資訊。此資料集的非商業與相同方式分享限制，也應納入後續模型及衍生資料的發布評估。

專案不將原始影像提交至 Git；可使用 `scripts/import_realwaste.py` 從原始 ZIP 重新建立本機資料目錄。
